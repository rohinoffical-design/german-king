# Duetchh King

A static German vocabulary learning website for A1 and A2 learners. It includes topic and level filters, flashcards, pronunciation, examples, verb forms, a quiz, and King's Word Quest.

## Publish with GitHub Pages

1. Put `index.html` at the root of a GitHub repository.
2. In the repository settings, open **Pages**.
3. Choose deployment from the `main` branch and the root folder, then save.
4. Share the GitHub Pages address shown there.

The site needs no build step or server code. Learned-word progress is stored separately in each visitor's browser.
